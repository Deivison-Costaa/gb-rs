## Objetivo

`ADD HL,r16` (`$09 $19 $29 $39`): 4 opcodes, `N=0` literal, `H`/`C` calculados sobre o par de 16 bits (carry do bit 11 e do bit 15). `Z` não afetada. `fetch → internal`, 2 M-cycles.

## Erros de primeira tentativa

| # | Categoria | O que eu assumi | O que a spec diz | Como foi pego |
|---|---|---|---|---|
| 1 | testes | 0xF000 + 0x1000 estoura bit 11 (H) | bits 0–11 de ambos são zero → H=0 | teste falhou: H não estava setado |
| 2 | testes | `ADD HL,HL` se comporta como os outros três pares | source = HL = destination: `set_hl` depois de `pair.set` pisa no valor do source | 5 de 9 testes falharam para $29; dados de entrada errados, não implementação |
| 3 | nenhum |  |  |  |

Nota sobre o #1: eu assumi que 0xF000 + 0x1000 geraria carry do bit 11 porque o nibble 12 muda. Mas o bit 11 é o 12o bit, e os bits 0–11 de ambos os operandos são zero — não há carry para o bit 12. O H é carry *into* bit 12, não *from* bit 12. Corrigido testando com valores que de fato geram carry do bit 11 (0x0FFF + 0x0001).

Nota sobre o #2: os testes iteravam sobre 4 pares e faziam `pair.set(&mut cpu, value); cpu.registers.set_hl(other_value)`. Para BC/DE/SP isso é independente. Para HL, `pair.set` chama `set_hl`, que é sobrescrito por `set_hl` na linha seguinte. Corrigido tratando o caso HL=HL separadamente.

## Decisões de arquitetura

Nenhuma nova. `ADD HL,r16` segue o padrão do 1.7a (`IncDecR16`): `fetch` escreve a metade baixa e latcha o par, `internal` escreve a alta. A diferença é que agora o `fetch` também calcula H/C e seta N=0. A escolha de `add_hl_r16` como método de `Cpu` (e não em `alu.rs`) é deliberada: `alu.rs` opera sobre `r8`, e os cálculos de H/C para 16 bits são diferentes (bit 11 vs bit 3).

## Notas

Nenhuma nova. O principal achado foi processual: os dados de teste que pareciam bons para os pares BC/DE/SP (0xF000 + 0x1000 "estoura bit 11") estavam errados — os bits 0–11 de 0xF000 e 0x1000 são todos zero. Só a suíte parametrizada que roda 4× revela esse tipo de erro: a combinação errada é improvável e o teste passa nos outros três pares.
