## Decisões de arquitetura

- RAM alocada como 512 bytes (`Box<[u8]>`), um por endereço no espaço `$A000–$A1FF`. Cada byte guarda só o nibble baixo. A alternativa compacta (256 bytes com dois nibbles cada) complicaria o cálculo de offset sem ganho mensurável — 512 bytes são desprezíveis.
- `ram_offset` usa `& (RAM_LEN - 1)` em vez de `% RAM_LEN`: `RAM_LEN` é potência de 2 (512) e o compilador não otimiza `%` para `&` em todos os casos.
- Sem `bank_mask` como no MBC1: MBC2 tem no máximo 16 bancos (4 bits), a máscara de 4 bits é o próprio `value & 0x0F`.
- O dispatch em `load()` segue o mesmo padrão do MBC1: `Mbc2::new(rom, rom_banks)`, `.with_battery()` condicional.
